กรอกข้อมูล 5 ขั้นตอน ประมาณ 7 นาที แล้วกดสร้าง — ได้ dashboard ส่วนตัวพร้อมกราฟจำลองกรณีตลาดแย่ และคำแนะนำจากกูรู 4 สำนัก ข้อมูลทั้งหมดเก็บอยู่ในเครื่องคุณเท่านั้น

1. ข้อมูลส่วนตัว

ระบบจะคำนวณอายุให้อัตโนมัติ
ถ้าตั้งใจทำงานไปเรื่อยๆ ใส่อายุที่คิดว่าจะทำไหวถึง
แนะนำ 90 ขึ้นไป — วางแผนสั้นเกินไปอันตรายกว่ายาวเกินไป

2. รายได้ (สุทธิหลังภาษี)

เลือกได้ว่าเป็น /เดือน หรือ /ปี — ดอกเบี้ยหุ้นกู้ พันธบัตร เงินฝาก หรือสวนผลไม้ที่ขายปีละครั้ง ใส่แบบ /ปี ได้เลย ระบบเฉลี่ยให้เอง
รวมรายได้: 0 บาท/เดือน (0 บาท/ปี)

3. ค่าใช้จ่าย

ใส่ให้ครบตามจริง รวมค่าผ่อนหนี้ ค่าดูแลพ่อแม่ ค่าเทอมลูก — ตัวเลขที่ต่ำกว่าจริงทำให้แผนดูดีเกินจริง · รายการที่จ่ายปีละครั้ง (เบี้ยประกัน ถ่ายน้ำมันเครื่อง ตรวจสุขภาพ ค่าทำสวน) เลือก /ปี ได้เลย
รวมค่าใช้จ่าย: 0 บาท/เดือน (0 บาท/ปี)
ปกติ 60-80% ของวันนี้ — หักค่าผ่อนหนี้ที่จะหมดและค่าเลี้ยงลูกที่จะโตแล้ว

4. ค่าใช้จ่ายก้อนใหญ่ครั้งเดียว

สิ่งที่ทำให้แผนจริงพังบ่อยกว่าเงินเฟ้อ — ค่าเทอมมหาวิทยาลัยลูก เปลี่ยนรถ ซ่อมบ้าน งานแต่งลูก ค่ารักษาก้อนโต ทริปใหญ่ ใส่เป็นมูลค่าเงินวันนี้ ระบบจะปรับเงินเฟ้อให้เอง
รวม: 0 บาท

5. รายได้ก้อนใหญ่ครั้งเดียว

เงินก้อนที่จะได้รับในอนาคต — RMF/Thai ESG ครบกำหนด กองทุนสำรองเลี้ยงชีพตอนออกจากงาน เงินชดเชยเกษียณ ประกันสะสมทรัพย์ครบสัญญา มรดก ขายที่ดิน · ใส่จำนวนที่คาดว่าจะได้รับจริงในปีนั้น (ไม่ต้องปรับเงินเฟ้อ)
รวม: 0 บาท

6. สินทรัพย์และหนี้สิน

เงินสด เงินฝาก กองทุน หุ้น ทอง — ไม่รวมที่ดิน/บ้าน

ที่ดิน / อสังหาฯ / สินทรัพย์ก้อนใหญ่

ใส่มูลค่าประเมิน + รายได้ที่ได้จริง เลือกได้ว่าเป็น /เดือน หรือ /ปี (สวนผลไม้ที่ขายปีละครั้ง เลือก /ปี) · ไม่มีรายได้ใส่ 0 · ติ๊กถ้าตั้งใจจะขาย พร้อมระบุอายุที่จะขาย
ประกันสังคม กบข. กองทุนสำรองเลี้ยงชีพ ประกันบำนาญ — ไม่รู้ตัวเลขใส่ 0 ไปก่อน ปรับทีหลังใน dashboard ได้

ข้อมูลนี้เป็นเพียงการวิเคราะห์เบื้องต้น ควรปรึกษาผู้เชี่ยวชาญด้านการเงินที่มีใบอนุญาตก่อนตัดสินใจลงทุน · ผลตอบแทนในอดีตไม่ได้การันตีอนาคต · ข้อมูลเก็บในเครื่องของคุณเท่านั้น (localStorage) ไม่มีการส่งออกไปที่ใด · แบบจำลองนี้ไม่คิดภาษี และไม่ปรับรายได้ตามเงินเฟ้อ ทำให้ผลลัพธ์ระมัดระวังกว่าความเป็นจริงเล็กน้อย
